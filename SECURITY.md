# Security

Rillvia becomes the default web browser while rules are on, so it takes security reports seriously.

## Reporting a vulnerability

Please report privately through [GitHub's private vulnerability reporting](https://github.com/masterdisk/Rillvia/security/advisories/new) rather than a public issue. Include the macOS version, the steps or link that trigger the problem, and what an attacker could achieve.

You'll get a reply as soon as possible. Fixes ship in a new release, and the advisory credits you unless you prefer otherwise.

## Supported versions

Only the latest release receives fixes. Update from **Settings → Updates**.
